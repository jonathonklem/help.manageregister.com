# Cashier Report

The Cashier Report provides a breakdown of sales activity by individual cashier. Use it to track employee performance and verify transaction accuracy.

---

## Running the Report

1. Go to **Report > Cashier Report**.
2. Select the **date range** and optionally filter by **cashier**.
3. Review the results.

---

## What You'll See

- Sales totals per cashier
- Number of transactions handled
- Payment method breakdown by cashier

---

## Tips

- Use this report to identify top-performing cashiers and provide coaching where needed.
- Cross-reference with the Z-Report for end-of-day reconciliation.
