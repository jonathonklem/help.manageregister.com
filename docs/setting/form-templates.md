# Form Templates

Form Templates let you create reusable forms for work orders and other processes. Templates save time by pre-defining the fields and structure for common workflows.

---

## Creating a Form Template

1. Go to **Setting > Form Templates**.
2. Click **"New Form Template"**.
3. Fill in:
   - **Template Name**: A descriptive name for the template.
   - **Category**: Choose from **Gunsmithing**, **General**, **Repair**, or **Custom**.
   - **Description**: Use the rich text editor to describe the template's purpose and instructions.
   - **Fields**: Configure the dynamic fields that will appear when using this template.
   - **Active**: Toggle whether this template is available for use.

---

## Template List

The list shows all form templates with options to edit or delete.

---

## Editing a Template

Click **Edit** to update the template name, category, description, fields, or active status.

---

## Tips

- Create templates for your most common work order types to speed up the intake process.
- Use the **Active** toggle to temporarily disable templates without deleting them.
- Keep field configurations consistent across similar template categories for easier data comparison.
