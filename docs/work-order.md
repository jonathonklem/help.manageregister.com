# Work Order

Work Orders let you track repair jobs, gunsmithing services, and other labor-based work for customers.

---

## Creating a Work Order

1. Go to **Work Order**.
2. Click **"Create Work Order"**.
3. Fill in the details:
   - **Customer**: Select an existing member or create a new one inline.
   - **Status**: Starts as **Open** by default.
   - **Assigned To**: Choose the technician handling the work.
   - **Notes**: Add customer-facing or internal notes.

---

## Adding Firearms

Each work order can track one or more firearms:

- **Brand** and **Model**
- **Caliber**
- **Serial Number**
- **Condition**

---

## Adding Labor Items

Track labor with hourly billing:

- **Description**: What work is being performed.
- **Hours**: Time spent.
- **Rate**: Hourly rate.
- **Amount**: Automatically calculated from hours and rate.

---

## Status Workflow

Work orders move through these statuses:

| Status | Meaning |
|--------|---------|
| **Open** | Work order created, not yet started |
| **In Progress** | Work is actively being done |
| **Completed** | Work is finished |
| **Picked Up** | Customer has retrieved their item |
| **Cancelled** | Work order was cancelled |

---

## Quotes & Receipts

- Generate a **quote** to send to the customer before work begins.
- Generate a **receipt** once the work is completed.
- Both can be emailed directly to the customer.

---

## Work Order List

The list view shows:

- Work order ID
- Customer name
- Number of firearms
- Current status
- Assigned technician
- Quote and final totals
- Created date

---

## Tips

- Always assign a technician so you can track who handled each job.
- Use the notes field to document any special instructions or customer requests.
- Generate quotes before starting work to set expectations with the customer.
